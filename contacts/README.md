# Your contacts

`contacts.csv`: people you've met or want to meet, with when you last talked and when to follow up. The blank file is set up the first time you open this folder.

This file is yours (and holds other people's details): it is not part of the app's download, git ignores it, and an update never changes it. Back it up with `/my-data`.

For the assistant: the same date and CSV rules as the tracker (AGENTS.md). Mark someone contacted only once a message was actually sent, with the date it was sent.
