# Your jobs

`tracker.csv` (your applications; opens in Excel), `leads.csv` (openings found but not yet saved), and one folder per job with its posting, fit notes, resume, cover letter and interview prep. The blank tracker and leads files are set up the first time you open this folder.

These files are yours: they are not part of the app's download, git ignores them, and an update never changes them. Back them up with `/my-data`.
