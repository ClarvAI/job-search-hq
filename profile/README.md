# Your profile

Your own files: master resume, stories, preferences, writing style, references, signature and page look. They start as blank copies (from `templates/blank/profile/`) the first time you open this folder, and `/start` fills them in with you.

These files are yours: they are not part of the app's download, git ignores them, and an update never changes them. Back them up with `/my-data` ("back up my stuff").
