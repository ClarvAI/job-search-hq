# Your profile

Your own files: master resume, stories, preferences, writing style, references, signature and page look. They start as blank copies (from `templates/blank/profile/`) the first time you open this folder, and `/start` fills them in with you. Once you pick a look, `templates/` here holds your resume and cover-letter templates in that look (the old copy is kept as `<name>.previous.html` when an update rebuilds one).

These files are yours: they are not part of the app's download, git ignores them, and an update never changes them (apart from rebuilding those themed templates, as above). Back them up with `/my-data` ("back up my stuff").
