# LinkedIn facts (checked October 2026)

LinkedIn changes often. If the user sees something different on screen, trust their screen and update this file.

## Field limits

| Field | Limit | What people see first |
|---|---|---|
| Headline | 220 characters | about the first 60–80 characters in search results and on phones |
| About | 2,600 characters | about the first 300 characters before "see more" |
| Skills | up to 100 | up to 5 "top skills" chosen in the About section; up to 5 skills can be linked to each job |
| Connection-request note | 200 characters; free accounts get 3 personalized notes a month (LinkedIn help) | |

## Open to Work

Three visibility settings (LinkedIn help):
- **All LinkedIn members:** adds the green #OpenToWork photo frame; everyone, including people at the current employer, can see it.
- **Recruiters only:** no frame; shown only to people using LinkedIn's paid Recruiter product. LinkedIn tries to hide it from recruiters at the user's current company (based on the job marked "I currently work here") but says it "can't guarantee complete privacy". It does nothing for recruiters on a normal account.
- **Visible only to you:** just tunes the user's own job recommendations.

The user can list up to 5 target job titles, locations (including remote), job types and start date; these feed recruiter search filters.

**Does the green frame hurt?** Evidence vs. opinion: LinkedIn says members with the public frame get noticeably more recruiter messages (its own data, not independently checked). The "it looks desperate" view is a recurring social-media argument; when HR Brew asked recruiters, most said they use the frame to find people. Reasonable advice: employed → recruiters only; not employed → either is fine, and the profile itself matters more.

## Creator mode and the Follow button

Creator mode was retired in 2024; its tools are now on by default. Profiles can make "Follow" the main button instead of "Connect" (in Settings & Privacy). For a job search, keep "Connect" as the main button so recruiters and alumni can connect easily.

## Recruiter search is getting AI help

LinkedIn's recruiter tools now include an AI "Hiring Assistant" that searches from a job description. Practical effect (our inference, not LinkedIn's guidance): a profile written in plain, specific words that match real job titles and tasks is found more easily than one stuffed with keywords.
