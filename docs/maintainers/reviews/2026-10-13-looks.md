## 3. Offline pages (P1-16)

- `templates/assets/` (3.04 MB, 70 files) holds the three libraries the pages load, byte-identical to the pinned CDN
  files (their SRI hashes match), and the theme fonts. Sources, versions, licenses and SHA-256 of every file:
  `templates/assets/manifest.json`; rebuilt by `scripts/ci/visual/build-assets.mjs` (npm packages, cached outside the
  repo), checked offline by `--check` (run in `theme-fixtures.sh`).
- Fonts: Fontsource latin + latin-ext subsets for the families with no Reserved Font Name (Bricolage Grotesque, Inter,
  JetBrains Mono, Fraunces, Source Serif 4, DM Sans, Space Grotesk, Work Sans, EB Garamond, Roboto, Open Sans); the
  complete unmodified files from Adobe (`source-sans` 3.52.0, `source-code-pro` 2.42.0) and IBM (`@ibm/plex-*`) for
  the families with one. Lexend (RFN "RevReading Lexend", no unmodified web file on npm) and Lato (RFN "Lato") still
  load from Google Fonts; offline they fall back to the system font in their stack.
- Pages: `apply-theme.mjs` writes the fonts line and each library line relative to the file (`../templates/assets/`
  from `pages/`, `../../` from `jobs/<folder>/` and `profile/templates/`). On a missing file the inline handler tries
  one folder up, then the same pinned CDN file with its integrity hash. Local files carry no `integrity` (browsers
  can't check it on file://); the product manifest fingerprints them. Preconnect hints to Google are gone.
- Published copies: `build-dashboard-data.mjs --publish-copy` now rewrites the dashboard copy to the pinned CDN tags
  with integrity and the Google Fonts link (artifacts allow those; relative files aren't there). Other pages' copies
  fall back by themselves.
- Verified in Chrome 155 with every http(s) request blocked: the four blank pages in `pages/` load Tailwind, ts-fsrs,
  confetti and all three fonts with 0 requests and 0 console errors; a brief copied to `jobs/<folder>/` also loads
  locally (one-level-up retry). The CORS console error the docs run saw came from axe-core's stylesheet preload, not
  the pages; the harness now runs axe with `preload: false` (only `css-orientation-lock` needs it; no page locks
  orientation).
- Page weight: a page loads Tailwind (254 KB) plus only the font files its theme uses (Default, English text: about 340 KB); nothing
  is inlined, so the agent never reads megabytes when it edits a data block. Published artifacts stay far under 16 MB.

## 4. Design leftovers

- **#17 brand accents near danger red: fixed in the token engine, measured.** The 15° hue rule is replaced by a
  measured one: the OKLab difference (x100) between the accent's text color and each status text color in light mode
  must reach 8 (the Default teal vs its green is 8.4). A status hue moves the least it can inside its family (red
  0–40°, amber 55–100°, green 125–165°, 15°+ from the accent) and says so in a `note:`. Results (light / dark):
  `#e4572e` danger 21° → 6°, 4.9 → 8.0 / 2.0 → 4.0; `#ff0000` 4.1 → 8.1; `#f97316` danger 27° → 20° and warning
  72° → 97°, 7.1 → 8.0; `#2e7d32` green 159° → 165° (3.3 → 4.4, the most the green family allows; noted). No preset
  moves (fixture). Subtle chip backgrounds stay close by nature (ΔE under 1); chips keep their word and icon.
- **#18 bento orphan card at 768 px: fixed.** Projects sit on a six-column grid: two across from 40rem with an odd last
  card spanning the row (cover 3:1), three across from 64rem with a last row of one spanning and of two sharing it.
- **PDF outline: on.** `make-pdf` (sh and ps1, via `pdf-common.sh`) passes `--generate-pdf-document-outline`; the
  multi-page academic CV and federal resume get bookmarks (qpdf shows `/Outlines`); older browsers ignore the switch.
- **#11 Type 3 fonts: neutral note, and now moot for documents.** Chrome embeds variable web fonts as Type 3 but static
  ones as CID TrueType (tested: static Roboto → CID TrueType, variable Source Sans 3 → Type 3). The four resume fonts
  now ship as static 400/700 files, so their PDFs embed TrueType. The skill keeps a neutral note (all parse fine); it
  no longer steers anyone to system fonts.
- **Cost split (lead's request):** `page-review/SKILL.md` 17,858 → 5,295 bytes (router, severity, always-HIGH list,
  fixing, verifying, report) + `references/pages-and-print.md` 10,362 + `panels.md` 2,757 + `copy.md` 2,023; every
  check kept (updated for the new options). `page-design/SKILL.md` 16,804 → 16,046 bytes (with the lead's shorter description) while documenting three
  presets, four layouts and three documents: "Without Node" moved to `references/without-node.md` (2,523), "Offline
  assets" into `references/page-building.md`. Neither description changed.
