## Summary

69 raw findings, 8 duplicates, **61 unique**: 46 CONFIRMED, 12 PARTLY, 3 REJECTED.
Severity of the 58 confirmed or partly confirmed: **0 critical, 6 high, 20 medium, 32 low**.

All six high findings are ways around the public-repository check in the guard, and each one also passes `guard.ps1`. SECURITY.md:37 says the check "follows git aliases, `-c` settings, URL rewrites and SSH host aliases". Each one needs an agent to write an unusual command and GitHub credentials to be present. The opt-in pre-push hook catches some of them, but not the trailing-dot host.

Guard probe results (sh and ps1 gave the same result in every case): the six high cases above, C-03, C-04, J4-14 and the GraphQL mutation all returned **allow**. The controls returned **deny**: a plain public push, an explicit public URL, an inline `GIT_CONFIG_*` prefix, `gh release upload ... --repo` placed after the subcommand, `gh api repos/...` writes, plain linkedin.com, and `send_and_get` with underscores. With the trailing-dot URL, pre-push exited 0; with the normal host it blocked (rc=1).
